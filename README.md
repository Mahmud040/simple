# BringIt - Peer-to-Peer Mock Delivery Platform

BringIt is a beginner-friendly, procedural JavaScript web application that simulates a peer-to-peer delivery service. It uses `localStorage` to handle data, making it a perfect starting point for learning web development without needing a complex backend.

## 🚀 Project Overview
*   **Static Client-Side App**: No server required.
*   **Mock Database**: Uses browser `localStorage` for persistent data during sessions.
*   **Responsive Design**: Built with Tailwind CSS.
*   **Feature Rich**: Includes authentication, request feeds, profile management, and a leaderboard.

## 🛠️ Tech Stack
*   **HTML5**
*   **Tailwind CSS** (via CDN)
*   **Vanilla JavaScript** (Procedural)
*   **Lucide Icons** (via CDN)

## 📂 Project Structure
*   `js/lib/`: Core logic for simulated database (`db.js`) and authentication (`auth.js`).
*   `js/components/`: Reusable UI elements like the navbar and utility functions.
*   `js/pages/`: Page-specific logic for the feed, creating requests, profile, etc.

## 🚦 Getting Started
1.  Clone the repository.
2.  Open `index.html` in your favorite web browser.
3.  Start exploring the peer-to-peer delivery simulation!

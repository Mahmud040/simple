Data Dictionary

Element Type Description Data Fields / Notes
Requester External Entity A campus student who needs an item picked up and delivered. Posts requests, tracks own requests, cancels open requests, bookmarks requests, views details.
Deliverer External Entity A campus student who browses open requests and volunteers to deliver. Accepts requests, marks them complete, bookmarks requests, views details.
1.0 Manage Authentication Process Handles user registration, login, and session management. Validates credentials and redirects unauthenticated users. Inputs: email password name studentId
Outputs: authToken sessionData
Source: auth.js
2.0 Post Request Process Multi-step form wizard for creating a new delivery request. Supports draft saving between steps. Inputs: title description category reward pickupLocation dropoffLocation
Outputs: saved request object
Source: create.js
3.0 Track Request Process Shows the current user's posted requests with their live statuses (open / accepted / completed). Includes Accept-initiated cancel flow. Inputs: userId
Outputs: requestList[] filtered by user
Source: my-requests.js
4.0 Cancel Request Process <<include>> from Track Request. Permanently deletes an open request posted by the requester. Inputs: requestId
Outputs: request removed from D2
Source: my-requests.js → handleDelete()
5.0 Bookmark Request Process Toggles a bookmark on any request for the logged-in user. Used in both Feed and Details pages. Inputs: userId requestId
Outputs: isBookmarked (true/false)
Source: feed.js → handleBookmark(), details.js → handleBookmarkToggle()
6.0 View Details Process Renders full information for a single request including status, locations, reward, bookmark state, and available actions. Inputs: requestId (URL param)
Outputs: rendered request card + action buttons
Source: details.js
7.0 Accept Request Process Atomically assigns an open request to the Deliverer, preventing race conditions. Validates the deliverer is not the original requester. Inputs: requestId delivererId delivererName
Outputs: request status → accepted
Source: db.js → acceptRequest(), feed.js → handleAccept()
8.0 Complete Request Process <<include>> from Accept Request. Marks a task as completed, updating the deliverer's leaderboard stats. Inputs: requestId
Outputs: request status → completed
Source: my-requests.js → handleComplete()
D1: Users Store Data Store Persistent store of all registered user accounts (localStorage key: BringIt_users). id name email studentId password
D2: Requests Store Data Store All delivery requests in the system (localStorage key: BringIt_requests). Status lifecycle: open → accepted → completed (or deleted). id title description category reward pickupLocation dropoffLocation postedBy postedByName postedAt status acceptedBy acceptedByName acceptedAt
D3: Bookmarks Store Data Store Junction table linking users to their bookmarked requests (localStorage key: BringIt_bookmarks). userId requestId
D4: Session Store Data Store Holds the currently logged-in user's profile for the active browser session (localStorage key: BringIt_session). id name email studentId
